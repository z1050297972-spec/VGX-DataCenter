# 导航层盘点：`/mnt/datasets` 的 210 份 JSON 与 84 条软链接

- 对应决策票：`.scratch/platform-v1/issues/01-nav-json-inventory.md`
- 盘点日期：2026-10-21
- 方法：用一个只读 Python 脚本（附录 A）遍历两个视图下的 70 个数据集目录，读取全部 210 份 JSON，再对 JSON 里出现的每个路径做 `lstat`/`readlink`。全程只读，没有写 `/mnt`。
- 本文的数字都是当天的快照。导航层或数据盘之后有变动，用附录 A 重跑。
- 各节的"来源"都指附录 A 的脚本输出，另有单独命令的会注明。

## 结论速览

1. **整体结构与 0002 F2 一致**。35 个数据集 × 2 个视图 = 70 个目录，每个目录正好 3 份 JSON（共 210 份），没有其他文件。两个视图各有 42 条软链接（共 84 条），没有断链。磁盘上的链接与 `links[]` 完全一一对应（§3）。
2. **schema 稳定，偏离集中在少数数据集**。三种 JSON 的核心字段在 70 份里全部出现，类型一致。`原始路径.json` 和 `子任务.json` 的 `schema_version` 都是 1，`数据集信息.json` 没有 `schema_version`。额外字段只出现在两个智元数据集，以及 12 个按 episode 选取子任务的数据集里（§1）。
3. **`按格式` 视图不一定是副本**。`数据集信息.json` 35 对全部逐字节相同；`原始路径.json` 有 33 对只在 `view`/`format`/`version`/`entry_path` 上不同，符合 F4。例外是 EgoProStandard 和 EgoProDemo：它们在 `按格式` 里的链接指向数据集内部的格式子目录；EgoProDemo 的 `按格式` 视图还少了 1 条 mcap source 和 1 个子任务。所以 `按格式` 视图实际是"数据集在该格式下的那一部分"（§2）。
4. **链接形态**：单链 32 个，跨盘 1 个（EgoProStandard），按子目录链接 2 个（两个智元数据集）。`按格式` 下 lerobot 深 4 层（有版本层），mcap 和 tar 深 3 层（§3）。
5. **失效引用分两类**（§4）：
   - 全局性的：`summary_path` 70/70 指向已经不存在的汇总文档；`文档/` 里有 8 处引用不存在的 `/mnt/datasets/预览/`。
   - **导航层写好之后，磁盘又被改过**：两个智元数据集下有 3 个目录（`lerobot_v2_output`、`extracted`、`scripts`）在 10-17 被删除，但 JSON 里还在引用它们。
6. **取值集合都很小**，可以直接做成枚举（§5）。注意 `按格式/tar、tar.gz（含分卷）/` 下的 `format` 值是 `archives`，目录名和格式值不一致。
7. **"数据大小"能解析成字节数**。35 条都带精确字节数，其中 34 条写法统一，EgoProStandard 多了"合计 + 分盘"。但这些都是 10-12 的快照，不是当前值（§6）。
8. **`子任务.json` 体积悬殊**：中位数 3.7 KB，最大的 agibot_world_2026 有 14.1 MB，其次是 EgoProStandard 的 1.0 MB（§7）。
9. **`解压样本/` 里有 224 GB 真实数据，放在系统盘上**。这与 F1 "导航层里只有软链接和 JSON"的说法不符（§8）。
10. **假导航层样本**：5 个数据集就能覆盖全部链接形态、目录深度和已知的特殊情况（§9）。

## 1. 三种 JSON 的 schema

### 1.1 `原始路径.json`

- `schema_version`：70/70 为 `1`。
- 顶层核心字段（11 个，70 份全有，顺序也相同）：`schema_version`、`dataset_id`、`dataset_name`、`dataset_roots`、`view`、`format`、`version`、`links`、`sources`、`notes`、`source_files_modified`。
- `links[]` 每项：`name`、`source_path`、`entry_path`、`source_type`。
- `sources[]` 每项：`source_id`、`original_path`、`direct_path`、`format`、`version`、`entry_path`、`source_role`、`validation_status`。
- 类型：只有顶层的 `format`、`version` 和 `sources[].version` 有 `null | string` 两种类型（`null` 表示没有这一层），其余字段的类型都唯一。

只出现在部分数据集里的字段：

| 字段 | 出现在 | 内容 |
|---|---|---|
| `navigation_scope` | agibot_world_2026、agibot_world_alpha | 都是 `original_component_or_category_directories` |
| `excluded_from_navigation` | 同上 | 没建链接的目录：2026 是 `extracted`、`scripts`，alpha 是 `lerobot_v2_output`。**这 3 个目录现在都不存在了**（§4） |
| `archive_file_count`、`archive_format_counts` | agibot_world_2026 | `404`；`{"tar.gz": 323, "分卷": 81}` |
| `task_metadata[]` | agibot_world_alpha | 36 项，每项为 `{task_key, task_info{source_path, entry_path, record_count, record_count_note, source_sha256}}` |
| `sources[].entry_type` | 两个智元数据集 | `through_direct_dataset_symlink`（619 条）、`original_source_path`（3 条） |
| `notes[]` 非空 | 两个智元数据集 | 各 3 条，说明"按用户要求只链接四个原始组件/分类目录" |

其他观察：

- `dataset_id` 写作 `dataset-01` … `dataset-35`，两位补零，没有缺号。
- `source_id` 写作 `src_` + 12 位十六进制，`按任务` 视图里 1849 条全部唯一。
- 1849 条 source 的 `original_path` 和 `direct_path` 全部相同。
- `sources[].entry_path` 有 1846 条是相对 `/mnt/datasets` 的路径，3 条是绝对路径。这 3 条是 alpha 里 `entry_type=original_source_path` 的条目，指向的正好是已删除的目录。
- `source_files_modified` 35/35 为 `false`。
- 每个数据集的 source 数：29 个数据集各 1 条；R1_lite_table_withdrawing_mcap 3 条；galaxea_open_world 227 条；alpha 215 条；EgoProDemo 234 条（`按格式` 视图里是 233 条）；agibot_world_2026 407 条；EgoProStandard 734 条。合计 `按任务` 1849 条、`按格式` 1848 条。

### 1.2 `数据集信息.json`

- **没有 `schema_version`**（70/70）。
- 顶层字段（9 个，70 份全有）：`dataset_id`、`title`、`fields`、`summary_path`、`summary_sha256`、`summary_anchor`、`snapshot_date`、`extracted_at`、`information_scope`。0002 F5 漏列了 `information_scope`。
- `title` 的写法是 `"NN. <dataset_name>"`；`summary_anchor` 等于 `dataset_id`。
- `fields[]`：35 个数据集都是 14 项，每项 `{number, name, value_markdown}`，编号、名称和顺序完全一致（与 F5 列的 14 项相同）。
- `snapshot_date` 35/35 为 `2026-10-12`。`summary_sha256` 70/70 是同一个值，即那份已删除的汇总文档的哈希。
- `information_scope` 35/35 是同一句话："原汇总中该数据集的14项原文与快照日期；不是本格式视图重新统计的大小或轨迹数。"
- `value_markdown` 是自由文本，其中嵌了 123 个 `[...](<路径>)` 形式的本地链接（§4 检查过）。

### 1.3 `子任务.json`

- `schema_version`：70/70 为 `1`。
- 顶层核心字段（11 个）：`schema_version`、`dataset_id`、`dataset_name`、`view`、`format`、`version`、`task_count`、`data_unit`、`semantics`、`tasks`、`shared_source_roots`。另有 `archive_instruction_details` 只出现在 agibot_world_2026，它是一个很深的嵌套结构，这份文件有 14 MB 主要就是因为它。
- 70 份文件里 `task_count` 都等于 `len(tasks)`。
- `semantics` 70/70 有 4 个键：`task_labels`、`source_sequences`、`scope`、`video_mapping`（都是中文说明文字）。
- `tasks[]` 核心字段（12 个）：`task_key`、`family`、`display_name`、`description`、`label_status`、`notes`、`sources`、`checked_at`、`entry_path`、`dataset_ids`、`entry_paths`、`subtask_json_paths`。
  - 只在 agibot_world_2026 里出现的：`category`、`scene`（`null | string`）、`original_task_id`、`original_task_titles`、`operation_examples`、`name_evidence`、`name_granularity`、`metadata_scan`（`null | object`）、`source_directory`。
  - 只在 agibot_world_alpha 里出现的：`task_info`。
- `tasks[].sources[]` 核心字段（8 个）：`source_id`、`root`、`scope`、`evidence`、`format`、`validation_status`、`entry_path`、`entry_type`。部分出现的字段：
  - `version`：**非 LeRobot 的 source 直接省略这个键**（mcap、archives、agibot_native、hdf5、auxiliary 都这样），而 `原始路径.json` 里同样的 source 写的是 `"version": null`。两份文件对"没有版本"的表示方法不一致。
  - `episode_indices`、`selection_semantics`：只出现在按 episode 选取的 12 个数据集里（cmu_stretch、droid_100、jaco_play、libero_10/90/goal/object/spatial、robocasa_gr1_tabletop、robocasa_target_human_unified、robotwin_unified、utokyo_pr2_tabletop）。
  - `component`：EgoProDemo、EgoProStandard、R1_lite_table_withdrawing_mcap 里的值是 `mcap`；alpha 里的值是 `observations`/`proprio_stats`。
  - `codebase_version`、`total_episodes`、`notes`：只出现在两个智元数据集；`observed_archives`、`observed_episode_directory_ids` 只出现在 alpha。
  - `evidence[].说明`：只有 robotwin_unified 有（53 处），**键名是中文**。
- `shared_source_roots`：70 份文件都有这个键，但只有上面那 12 个数据集里非空。
- **子任务可以同时属于多个数据集**：`按任务` 视图里共有 1467 个任务条目，`task_key` 去重后是 1465 个。`libero_v3_2a3da0cbc71b` 同时出现在 libero_10 和 libero_90 里，`libero_v3_c0d1b2f3264d` 同时出现在 libero_90 和 libero_goal 里，它们的 `dataset_ids` 也都列了两个数据集。

## 2. 两个视图的副本

| 检查 | 结果 |
|---|---|
| 每个 `dataset_id` 在两个视图里各出现一次 | 35/35 |
| 同一目录下 3 份 JSON 的 `dataset_id` 一致 | 70/70 |
| 目录名等于 `dataset_name` | 70/70 |
| `数据集信息.json` 两个视图相同 | 35/35，逐字节相同 |
| `原始路径.json` 只在 `view`/`format`/`version`/`entry_path` 上不同（F4） | 33/35；例外是 EgoProStandard、EgoProDemo |
| `子任务.json` 只在顶层 `view`/`format`/`version` 上不同 | 34/35；例外是 EgoProDemo |

### 2.1 例外一：EgoProStandard（dataset-32）

- `按任务`：`原始数据__dataset1 → /mnt/dataset1/EgoProStandard`，`原始数据__dataset2 → /mnt/dataset2/EgoProStandard`。
- `按格式/mcap`：`原始数据__dataset1 → /mnt/dataset1/EgoProStandard/mcap`，`原始数据__dataset2 → /mnt/dataset2/EgoProStandard/mcap`。
- `dataset_roots` 和 734 条 source 在两个视图里相同，只是 `entry_path` 随链接目标变化。

### 2.2 例外二：EgoProDemo（dataset-33）

- `按任务`：`原始数据 → /mnt/dataset2/EgoProDemo`。有 234 条 source（233 条 lerobot 3.0 + 1 条 mcap），94 个子任务。
- `按格式/lerobot/3.0`：`原始数据 → /mnt/dataset2/EgoProDemo/EgoProStandard-body/lerobot`。只有 233 条 source（没有那条 mcap），93 个子任务（少了 `EgoProDemo_931dd2a2a231`「原生MCAP样例__任务待核验」）。
- EgoProDemo 里的 mcap 部分没有出现在 `按格式/mcap/` 下。也就是说，一个包含多种格式的数据集，在 `按格式` 里只占一个位置。

### 2.3 其他差异

- agibot_world_alpha 的 `task_metadata[].task_info.entry_path` 在两个视图里前缀不同。这和 F4 说的 `entry_path` 差异是同一类，只是位置更深。
- `按格式` 目录与 `format`/`version` 字段的对应关系：

| 目录 | `format` | `version` |
|---|---|---|
| `按格式/lerobot/3.0/` | `lerobot` | `"3.0"` |
| `按格式/mcap/` | `mcap` | `null` |
| `按格式/tar、tar.gz（含分卷）/` | **`archives`** | `null` |

  `按任务` 视图的三个字段是 `view=task`、`format=null`、`version=null`。

| 形态 | 链接名 | 数据集数 | 数据集 |
|---|---|---:|---|
| 单链 | `原始数据` | 32 | dataset1 上 28 个；dataset2 上 4 个：EgoProDemo、R1_lite_table_withdrawing_lerobot、R1_lite_table_withdrawing_mcap、galaxea_open_world |

**磁盘与 `links[]` 的一致性**（84 条链接全部通过）：

- 目录里的链接名集合等于 `links[].name` 集合。
- `readlink` 的结果等于 `links[].source_path`（都是绝对路径）。
- `links[].entry_path` 等于 `<数据集目录>/<链接名>`。
- `links[].source_type` 与链接目标的实际类型一致，42 个都是 `directory`。
- 链接目标都落在 `dataset_roots` 之内。
- 断链：`find 按任务 按格式 -xtype l` 没有输出。

**按子目录链接时，根目录里有些东西不可见**：alpha 根目录下还有 `.venv_lerobot_v2`、`.venv_lerobot_v2_v21_v3`、`README.md`、`scripts/`。它们没有建链接，也没有写进 `excluded_from_navigation`，所以通过导航层看不到，也查不到它们被排除的记录。

**目录深度 × 链接形态**：

| 形态 | `按任务/<ds>`（2 层） | `按格式/<fmt>/<ds>`（3 层） | `按格式/<fmt>/<ver>/<ds>`（4 层） |
|---|---:|---:|---:|
| 单链 | 32 | 1（R1_lite_table_withdrawing_mcap） | 31 |
| 跨盘 | 1 | 1（EgoProStandard，mcap） | 0 |
| 按子目录 | 2 | 2（tar） | 0 |

`按格式/lerobot/2.0/` 和 `按格式/lerobot/2.1/` 是空目录。

`nav_inventory.py`：

```python
"""导航层只读盘点。用法：python3 -I nav_inventory.py /mnt/datasets > report.json

只做 open/read/stat/readlink，不写 /mnt 下任何东西。
"""
import collections
import hashlib
import json
import os
import re
import sys

ROOT = sys.argv[1] if len(sys.argv) > 1 else "/mnt/datasets"
KINDS = ["原始路径.json", "数据集信息.json", "子任务.json"]


def dataset_dirs():
    """返回 [(view, rel_dir)]，rel_dir 相对 ROOT。"""
    out = []
    for name in sorted(os.listdir(os.path.join(ROOT, "按任务"))):
        out.append(("task", f"按任务/{name}"))
    fmt_root = os.path.join(ROOT, "按格式")
    for fmt in sorted(os.listdir(fmt_root)):
        p = os.path.join(fmt_root, fmt)
        for child in sorted(os.listdir(p)):
            cp = os.path.join(p, child)
            if os.path.exists(os.path.join(cp, "原始路径.json")):
                out.append(("format", f"按格式/{fmt}/{child}"))
            else:
                for ds in sorted(os.listdir(cp)):
                    out.append(("format", f"按格式/{fmt}/{child}/{ds}"))
    return out


def walk_paths(obj, prefix, acc):
    """把 JSON 展平成 path -> 类型集合。列表元素用 []。"""
    t = type(obj).__name__
    acc[prefix].add(t)
    if isinstance(obj, dict):
        for k, v in obj.items():
            walk_paths(v, f"{prefix}.{k}", acc)
    elif isinstance(obj, list):
        for v in obj:
            walk_paths(v, f"{prefix}[]", acc)


def diff_paths(a, b, prefix=""):
    """返回 a、b 不同的叶子路径集合（列表按下标比）。"""
    out = set()
    if type(a) is not type(b):
        out.add(prefix or "<root>")
    elif isinstance(a, dict):
        for k in sorted(set(a) | set(b)):
            if k not in a or k not in b:
                out.add(f"{prefix}.{k}(missing)")
            else:
                out |= diff_paths(a[k], b[k], f"{prefix}.{k}")
    elif isinstance(a, list):
        if len(a) != len(b):
            out.add(f"{prefix}(len {len(a)} vs {len(b)})")
        for x, y in zip(a, b):
            out |= diff_paths(x, y, f"{prefix}[]")
    elif a != b:
        out.add(prefix)
    return out


def resolve_entry(p):
    return p if p.startswith("/") else os.path.join(ROOT, p)


def main():
    dirs = dataset_dirs()
    rep = {"dataset_dirs": len(dirs)}
    data = {}  # rel_dir -> {kind: obj}
    sizes = {}
    raw_sha = {}
    for view, rel in dirs:
        data[rel] = {"view_dir": view}
        for k in KINDS:
            fp = os.path.join(ROOT, rel, k)
            with open(fp, "rb") as f:
                b = f.read()
            raw_sha[(rel, k)] = hashlib.sha256(b).hexdigest()
            sizes[(rel, k)] = len(b)
            data[rel][k] = json.loads(b)

    # ---- 1. schema
    schema = {}
    for k in KINDS:
        acc_all = collections.defaultdict(lambda: collections.defaultdict(int))
        types = collections.defaultdict(set)
        topkeys = collections.Counter()
        sv = collections.Counter()
        for rel in data:
            acc = collections.defaultdict(set)
            walk_paths(data[rel][k], "$", acc)
            for p, ts in acc.items():
                acc_all[p]["files"] += 1
                types[p] |= ts
            topkeys[tuple(data[rel][k].keys())] += 1
            sv[repr(data[rel][k].get("schema_version", "<absent>"))] += 1
        n = len(data)
        schema[k] = {
            "paths": {p: {"files": acc_all[p]["files"], "types": sorted(types[p])} for p in sorted(acc_all)},
            "optional_paths": {p: acc_all[p]["files"] for p in sorted(acc_all) if acc_all[p]["files"] != n},
            "multi_type_paths": {p: sorted(types[p]) for p in sorted(types) if len(types[p]) > 1},
            "top_key_orders": {" ,".join(t): c for t, c in topkeys.items()},
            "schema_version": dict(sv),
        }
    rep["schema"] = schema

    # 哪些文件缺少可选字段：针对每个 optional path 列出含有它的 rel 目录（只到前 3 层路径）
    opt_owners = {}
    for k in KINDS:
        for p in schema[k]["optional_paths"]:
            if p.count(".") > 3:
                continue
            owners = []
            for rel in data:
                acc = collections.defaultdict(set)
                walk_paths(data[rel][k], "$", acc)
                if p in acc:
                    owners.append(rel)
            opt_owners[f"{k}:{p}"] = owners if len(owners) <= 40 else f"{len(owners)} files"
    rep["optional_path_owners"] = opt_owners

    # ---- 2. 两个视图配对
    by_id = collections.defaultdict(list)
    for rel in data:
        by_id[data[rel]["原始路径.json"]["dataset_id"]].append(rel)
    pairing = {"ids": len(by_id), "not_paired": {i: r for i, r in by_id.items() if len(r) != 2}}
    id_consistency = []
    info_diff, path_diff, sub_diff = {}, collections.Counter(), {}
    path_diff_examples = {}
    for i, rels in sorted(by_id.items(), key=lambda x: int(x[0].split("-")[1])):
        if len(rels) != 2:
            continue
        a, b = sorted(rels, key=lambda r: 0 if r.startswith("按任务") else 1)
        for k in KINDS:
            ids = {data[r][k].get("dataset_id") for r in rels}
            if len(ids) != 1:
                id_consistency.append((i, k, sorted(map(str, ids))))
        if raw_sha[(a, "数据集信息.json")] != raw_sha[(b, "数据集信息.json")]:
            info_diff[i] = sorted(diff_paths(data[a]["数据集信息.json"], data[b]["数据集信息.json"]))
        d = diff_paths(data[a]["原始路径.json"], data[b]["原始路径.json"])
        for p in sorted(d):
            path_diff[p] += 1
            path_diff_examples.setdefault(p, i)
        if raw_sha[(a, "子任务.json")] != raw_sha[(b, "子任务.json")]:
            sd = diff_paths(data[a]["子任务.json"], data[b]["子任务.json"])
            sub_diff[i] = collections.Counter(re.sub(r"\(len.*", "(len)", p) for p in sorted(sd))
    pairing["dataset_id_mismatch_within_dir"] = id_consistency
    pairing["info_json_not_identical"] = info_diff
    pairing["path_json_diff_paths"] = dict(path_diff)
    pairing["path_json_diff_example"] = path_diff_examples
    pairing["subtask_json_not_identical_count"] = len(sub_diff)
    pairing["subtask_json_diff_paths"] = {i: dict(c) for i, c in sub_diff.items()}
    # dataset_name 与目录名、format/version 与目录位置
    placement = []
    for rel in data:
        pj = data[rel]["原始路径.json"]
        parts = rel.split("/")
        if parts[-1] != pj["dataset_name"]:
            placement.append((rel, "dir!=dataset_name", pj["dataset_name"]))
        if rel.startswith("按任务"):
            if (pj["view"], pj["format"], pj["version"]) != ("task", None, None):
                placement.append((rel, "task view fields", pj["view"], pj["format"], pj["version"]))
        else:
            exp_fmt = parts[1]
            exp_ver = parts[2] if len(parts) == 4 else None
            if (pj["view"], pj["format"], pj["version"]) != ("format", exp_fmt, exp_ver):
                placement.append((rel, "format view fields", pj["view"], pj["format"], pj["version"]))
        for k in ("数据集信息.json", "子任务.json"):
            o = data[rel][k]
            for f in ("dataset_name", "view", "format", "version"):
                if f in o and o[f] != pj[f]:
                    placement.append((rel, f"{k}.{f}", o[f], pj[f]))
    pairing["placement_issues"] = placement
    ids_sorted = sorted(by_id, key=lambda x: int(x.split("-")[1]))
    pairing["id_range"] = [ids_sorted[0], ids_sorted[-1]]
    pairing["id_gaps"] = sorted(set(range(1, len(ids_sorted) + 1)) - {int(x.split("-")[1]) for x in ids_sorted})
    rep["pairing"] = pairing

    # ---- 3. 链接形态
    forms = collections.defaultdict(list)
    link_mismatch = []
    per_view_link_count = collections.Counter()
    depth_samples = collections.defaultdict(list)
    for rel in data:
        full = os.path.join(ROOT, rel)
        entries = sorted(os.listdir(full))
        links_disk = {e: os.readlink(os.path.join(full, e)) for e in entries if os.path.islink(os.path.join(full, e))}
        others = [e for e in entries if e not in links_disk and e not in KINDS]
        per_view_link_count[data[rel]["view_dir"]] += len(links_disk)
        pj = data[rel]["原始路径.json"]
        links_json = {l["name"]: l for l in pj["links"]}
        if set(links_disk) != set(links_json):
            link_mismatch.append((rel, "name set", sorted(links_disk), sorted(links_json)))
        for n, l in links_json.items():
            if n in links_disk:
                if links_disk[n] != l["source_path"]:
                    link_mismatch.append((rel, n, "readlink", links_disk[n], l["source_path"]))
                if l["entry_path"] != f"{rel}/{n}":
                    link_mismatch.append((rel, n, "entry_path", l["entry_path"]))
                tgt = os.path.join(full, n)
                st = "directory" if os.path.isdir(tgt) else ("file" if os.path.isfile(tgt) else "other")
                if st != l["source_type"]:
                    link_mismatch.append((rel, n, "source_type", st, l["source_type"]))
        disks = sorted({t.split("/")[2] for t in links_disk.values()})
        names = sorted(links_disk)
        if names == ["原始数据"]:
            form = "single"
        elif names and all(re.fullmatch(r"原始数据__dataset\d+", n) for n in names):
            form = "cross_disk"
        else:
            form = "per_subdir"
        roots = pj["dataset_roots"]
        if data[rel]["view_dir"] == "task":
            forms[form].append({
                "dataset": pj["dataset_name"], "id": pj["dataset_id"], "links": names,
                "targets": [links_disk[n] for n in names], "disks": disks, "dataset_roots": roots,
            })
        depth = rel.count("/") + 1
        depth_samples[(form, depth, data[rel]["view_dir"])].append(rel)
        if others:
            link_mismatch.append((rel, "unexpected entries", others))
        # dataset_roots 与链接目标关系
        for t in links_disk.values():
            if not any(t == r or t.startswith(r.rstrip("/") + "/") for r in roots):
                link_mismatch.append((rel, "link target outside dataset_roots", t, roots))
    rep["links"] = {
        "per_view_link_count": dict(per_view_link_count),
        "forms": {f: {"count": len(v), "items": v} for f, v in forms.items()},
        "mismatch": link_mismatch,
        "depth_form_matrix": {f"{f}|depth{d}|{v}": s for (f, d, v), s in sorted(depth_samples.items())},
    }

    # ---- 4. 失效引用
    refs = {}
    sp = collections.Counter(data[r]["数据集信息.json"].get("summary_path") for r in data)
    refs["summary_path_values"] = {k: {"count": c, "exists": os.path.exists(k)} for k, c in sp.items()}
    refs["summary_sha256_values"] = dict(collections.Counter(data[r]["数据集信息.json"].get("summary_sha256") for r in data))
    missing = collections.defaultdict(list)
    checked = collections.Counter()
    for rel in data:
        pj = data[rel]["原始路径.json"]
        for r in pj.get("excluded_from_navigation", []):
            checked["excluded_from_navigation"] += 1
            if not os.path.lexists(r):
                missing["excluded_from_navigation"].append((rel, r))
        for r in pj["dataset_roots"]:
            checked["dataset_roots"] += 1
            if not os.path.exists(r):
                missing["dataset_roots"].append((rel, r))
        for s in pj["sources"]:
            for f in ("original_path", "direct_path"):
                checked[f"sources.{f}"] += 1
                if not os.path.lexists(s[f]):
                    missing[f"sources.{f}"].append((rel, s["source_id"], s[f]))
            checked["sources.entry_path"] += 1
            if not os.path.lexists(resolve_entry(s["entry_path"])):
                missing["sources.entry_path"].append((rel, s["source_id"], s["entry_path"]))
    # 子任务里的路径（只查 task 视图一份，避免重复）
    sub_paths = collections.Counter()
    for rel in data:
        if data[rel]["view_dir"] != "task":
            continue
        sj = data[rel]["子任务.json"]
        for t in sj.get("tasks", []):
            for p in t.get("entry_paths", []) + ([t["entry_path"]] if "entry_path" in t else []) + t.get("subtask_json_paths", []):
                sub_paths[("tasks.entry/subtask paths", resolve_entry(p))] += 1
            for s in t.get("sources", []):
                if "root" in s:
                    sub_paths[("tasks.sources.root", s["root"])] += 1
                if "entry_path" in s:
                    sub_paths[("tasks.sources.entry_path", resolve_entry(s["entry_path"]))] += 1
                for e in s.get("evidence", []):
                    if "path" in e:
                        sub_paths[("tasks.sources.evidence.path", e["path"])] += 1
        for s in sj.get("shared_source_roots", []):
            sub_paths[("shared_source_roots.root", s["root"])] += 1
    for (cat, p), c in sub_paths.items():
        checked[f"subtask:{cat}(unique)"] += 1
        if not os.path.lexists(p):
            missing[f"subtask:{cat}"].append(p)
    refs["checked"] = dict(checked)
    refs["missing"] = {k: (v if len(v) <= 30 else {"count": len(v), "sample": v[:15]}) for k, v in missing.items()}
    refs["missing_counts"] = {k: len(v) for k, v in missing.items()}
    # 文档/ 里的路径引用
    doc_refs = {}
    doc_dir = os.path.join(ROOT, "文档")
    for fn in sorted(os.listdir(doc_dir)):
        txt = open(os.path.join(doc_dir, fn), encoding="utf-8").read()
        found = set(re.findall(r"/mnt/[^\s`'\")\]>|，。；：、]+", txt))
        doc_refs[fn] = {
            "size": len(txt.encode()),
            "refs": len(found),
            "missing": sorted(p for p in found if not os.path.lexists(p.rstrip(".,:;")))
        }
    refs["docs"] = doc_refs
    # 数据集信息.json 的 value_markdown 里的 markdown 链接
    md_missing = collections.defaultdict(list)
    md_checked = 0
    for rel in data:
        if data[rel]["view_dir"] != "task":
            continue
        for f in data[rel]["数据集信息.json"]["fields"]:
            for p in re.findall(r"\]\(<([^>]+)>\)", f["value_markdown"]) + re.findall(r"\]\((/[^)<>\s]+)\)", f["value_markdown"]):
                md_checked += 1
                if not os.path.lexists(p):
                    md_missing[data[rel]["数据集信息.json"]["dataset_id"]].append((f["number"], p))
    refs["info_markdown_links_checked"] = md_checked
    refs["info_markdown_links_missing"] = dict(md_missing)
    rep["refs"] = refs

    # ---- 5. 取值集合
    vals = collections.defaultdict(collections.Counter)
    for rel in data:
        if data[rel]["view_dir"] != "task":
            continue
        pj = data[rel]["原始路径.json"]
        for l in pj["links"]:
            vals["原始路径.links.source_type"][l["source_type"]] += 1
        for s in pj["sources"]:
            vals["原始路径.sources.validation_status"][s["validation_status"]] += 1
            vals["原始路径.sources.source_role"][s["source_role"]] += 1
            vals["原始路径.sources.format|version"][f'{s["format"]}|{s["version"]}'] += 1
            vals["原始路径.sources.entry_type"][s.get("entry_type", "<absent>")] += 1
            vals["原始路径.sources.entry_path_kind"]["absolute" if s["entry_path"].startswith("/") else "relative"] += 1
            vals["原始路径.sources.original==direct"][str(s["original_path"] == s["direct_path"])] += 1
        vals["原始路径.notes_len"][len(pj["notes"])] += 1
        vals["原始路径.source_files_modified"][str(pj["source_files_modified"])] += 1
        sj = data[rel]["子任务.json"]
        vals["子任务.data_unit"][sj.get("data_unit", "<absent>")] += 1
        for t in sj.get("tasks", []):
            vals["子任务.tasks.label_status"][t.get("label_status", "<absent>")] += 1
            vals["子任务.tasks.family"][t.get("family", "<absent>")] += 1
            vals["子任务.tasks.dataset_ids_len"][len(t.get("dataset_ids", []))] += 1
            for s in t.get("sources", []):
                vals["子任务.tasks.sources.scope"][s.get("scope", "<absent>")] += 1
                vals["子任务.tasks.sources.selection_semantics"][s.get("selection_semantics", "<absent>")] += 1
                vals["子任务.tasks.sources.validation_status"][s.get("validation_status", "<absent>")] += 1
                vals["子任务.tasks.sources.format|version"][f'{s.get("format")}|{s.get("version")}'] += 1
                vals["子任务.tasks.sources.entry_type"][s.get("entry_type", "<absent>")] += 1
        ij = data[rel]["数据集信息.json"]
        vals["数据集信息.snapshot_date"][ij.get("snapshot_date")] += 1
        vals["数据集信息.information_scope"][ij.get("information_scope", "<absent>")] += 1
        vals["数据集信息.fields_len"][len(ij["fields"])] += 1
        vals["数据集信息.field_names"][" / ".join(f'{f["number"]}:{f["name"]}' for f in ij["fields"])] += 1
    for rel in data:
        pj = data[rel]["原始路径.json"]
        vals["原始路径.top.view|format|version"][f'{pj["view"]}|{pj["format"]}|{pj["version"]}'] += 1
    rep["values"] = {k: dict(v.most_common()) for k, v in vals.items()}
    # 每个数据集的 sources 数量 & validation 分布
    per_ds = {}
    for rel in data:
        if data[rel]["view_dir"] != "task":
            continue
        pj = data[rel]["原始路径.json"]
        per_ds[pj["dataset_name"]] = {
            "id": pj["dataset_id"],
            "sources": len(pj["sources"]),
            "validation": dict(collections.Counter(s["validation_status"] for s in pj["sources"])),
            "formats": dict(collections.Counter(f'{s["format"]}|{s["version"]}' for s in pj["sources"])),
            "tasks": data[rel]["子任务.json"].get("task_count"),
            "tasks_len": len(data[rel]["子任务.json"].get("tasks", [])),
        }
    rep["per_dataset"] = per_ds

    # ---- 6. 数据大小
    # 34 条是「X TB / Y TiB（N B；Z GB）…」；EgoProStandard 前面多「合计」并附分盘明细。第一个「（N B；」总是总量。
    uniform_re = re.compile(r"^[\d.]+ TB / [\d.]+ TiB（[\d,]+ B；[\d.]+ GB）")
    bytes_re = re.compile(r"（([\d,]+) B；")
    sz = []
    for rel in data:
        if data[rel]["view_dir"] != "task":
            continue
        ij = data[rel]["数据集信息.json"]
        f4 = next(f for f in ij["fields"] if f["number"] == 4)
        m = bytes_re.search(f4["value_markdown"])
        sz.append({
            "id": ij["dataset_id"], "name": data[rel]["原始路径.json"]["dataset_name"],
            "raw": f4["value_markdown"], "uniform_prefix": bool(uniform_re.match(f4["value_markdown"])),
            "parsed_bytes": int(m.group(1).replace(",", "")) if m else None,
        })
    rep["data_size"] = sz

    # ---- 7. 子任务.json 体积
    sub_sizes = sorted(((sizes[(rel, "子任务.json")], rel) for rel in data if data[rel]["view_dir"] == "task"), reverse=True)
    rep["subtask_sizes"] = [{"bytes": b, "dir": r} for b, r in sub_sizes]
    buckets = [(4_000, "<4KB"), (100_000, "4KB-100KB"), (1_000_000, "100KB-1MB"), (10_000_000, "1MB-10MB"), (float("inf"), ">=10MB")]
    rep["subtask_size_buckets"] = dict(collections.Counter(next(n for lim, n in buckets if b < lim) for b, _ in sub_sizes))
    rep["all_json_sizes_by_kind"] = {
        k: {"min": min(sizes[(r, k)] for r in data), "max": max(sizes[(r, k)] for r in data),
            "total": sum(sizes[(r, k)] for r in data)} for k in KINDS
    }
    json.dump(rep, sys.stdout, ensure_ascii=False, indent=1, default=str)


if __name__ == "__main__":
    main()
```
