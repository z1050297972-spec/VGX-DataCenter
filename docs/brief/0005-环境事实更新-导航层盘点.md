## 修正 F1：导航层里不只有软链接和 JSON

- `/mnt/datasets/解压样本/` 里是两个真实目录，不是软链接，合计约 224 GB。主要是 `agibot_world_2026_simulation_scoop_popcorn_lite`（LeRobot v2.1，211 个 episode）。它们和导航层一样在系统盘 `/dev/nvme0n1p2` 上，系统盘还剩 332 G。
- `工具/mcap2lerobot` 有 2.1 GB，主要是 `target/` 下的构建产物。
- 来源：§8；`du -sh`、`findmnt -T`、`df -h /`

## 修正 F4：`按格式` 视图不一定是 `按任务` 的副本

- 35 个数据集里有 33 个符合 F4：`原始路径.json` 只在 `view`/`format`/`version`/`entry_path` 上不同。
- 例外：EgoProStandard、EgoProDemo 在 `按格式` 里的链接指向数据集内部的格式子目录（`…/mcap`、`…/EgoProStandard-body/lerobot`）。EgoProDemo 的 `按格式` 视图还少了 1 条 mcap source 和 1 个子任务，它的 mcap 部分也没有出现在 `按格式/mcap/` 下。
- `数据集信息.json` 在两个视图里 35/35 逐字节相同。`子任务.json` 有 34/35 只在顶层 `view`/`format`/`version` 上不同。
- `按格式/tar、tar.gz（含分卷）/` 下的 `format` 值是 `archives`，不是目录名。
- 来源：§2

## 修正 F5：字段清单和失效引用

- `数据集信息.json` 还有一个顶层字段 `information_scope`，并且**没有 `schema_version`**。`原始路径.json` 和 `子任务.json` 的 `schema_version` 都是 1。
- 两个智元数据集的 JSON 有额外字段：`excluded_from_navigation`、`navigation_scope`、`task_metadata`、`archive_*`、`sources[].entry_type`、`archive_instruction_details` 等。来源：§1
- 失效引用比 F5 记录的多：
  - 两个智元数据集下有 3 个目录在 10-17 被删除：`/mnt/dataset2/agibot_world_alpha/lerobot_v2_output`、`/mnt/dataset1/agibot_world_2026/extracted`、`/mnt/dataset1/agibot_world_2026/scripts`。但导航 JSON 是 10-16 写的，没有更新，仍在引用它们，涉及 `excluded_from_navigation`、3 条 source、子任务里的 root 和 evidence、`数据集信息.json` 的 1 个链接。
  - 这说明**数据盘已经发生过在平台之外的改动，而导航 JSON 没有同步**。来源：§4
- 补充：agibot_world_2026 里还留着一个 `.aria2` 下载控制文件，对应的 53.5 GB 归档可能不完整。来源：§4

- 单链 32 个，跨盘 1 个（EgoProStandard），按子目录 2 个（两个智元数据集）。每个视图 42 条，共 84 条。
