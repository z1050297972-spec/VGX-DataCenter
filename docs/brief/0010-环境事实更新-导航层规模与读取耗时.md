## 3. LeRobot 数据块的 `meta/info.json`

- **能读到的**：`format == "lerobot"` 的数据块共 494 条（按任务视图），其中 491 条有 `meta/info.json`。缺的 3 条，就是 agibot_world_alpha 那 3 个已删除的转换副本。全部读一遍不到 1 秒。
- **`robot_type`**：
  - 25 个数据集有具体的值，例如 `franka`、`aloha`、`galaxea_r1lite`、`g2a`。galaxea_open_world 有 `r1lite`、`r1pro` 两种。
  - 7 个数据集的值是 `"unknown"` 或 `null`：jaco_play、nyu_door_opening、tidybot_lerobot、unitreeh1_fold_clothes、utokyo_pr2_fridge、utokyo_pr2_tabletop 是 `"unknown"`，EgoProDemo 是 `null`。
  - agibot_world_alpha、EgoProStandard、R1_lite_table_withdrawing_mcap 不是 LeRobot，没有这项。
- **`fps`**：EgoProDemo 的 233 份 `info.json` 里有 25 种不同的取值，在 24.999 到 36.018 之间，以 25 和 30 附近为主。其余数据集每个只有一种取值。
- **`codebase_version`**：都是 `v3.0`，只有 agibot_world_2026 里的 `lite_old` 是 `v2.1`。491 条数据块登记的 `version` 和 `codebase_version` 全部一致。
- 来源：遍历 `按任务/*/原始路径.json` 的 `sources[]`，读 `<direct_path>/meta/info.json`。复跑用 `read_checks.py` 的第 2 段；各数据集的 `fps` 集合见 Codex 报告 `raw/codex-facts-report-20261022.md` 第 3 节。

## 4. 挂载信息（补充 F1）

- **两块数据盘**：
  - `/mnt/dataset1` 是 `/dev/sda`，ext4，UUID `2d3a48d6-3785-47fe-8c8f-a20857fdc41a`。
  - `/mnt/dataset2` 是 `/dev/sdb`，ext4，UUID `35445b14-9e83-4f74-ac73-1551e3db6d63`。
  - 本机上的挂载选项是 `rw,relatime`。Codex 的沙箱里看到的是 `ro`，那是沙箱自己的挂载命名空间。
- **设备号**：挂载点和父目录的设备号不同，`/mnt/dataset1` 是 2048，`/mnt/dataset2` 是 2064，`/mnt` 和 `/mnt/datasets` 都是 66306。
- **`findmnt` 的用法**：给 `findmnt` 两个位置参数时，它会理解成"设备 + 挂载点"，所以查一个挂载点要用 `--mountpoint`。
- **本机时区是 UTC−6**（`date +%z` 输出 `-0600`）。`数据集信息.json` 里 `extracted_at` 的 `-06:00` 和它一致。
- 来源：`findmnt -J -o TARGET,SOURCE,FSTYPE,UUID,OPTIONS --mountpoint …`、`grep ' /mnt/dataset[12] ' /proc/self/mountinfo`、`stat -c '%d %i %n'`、`date +%z`。

## 5. 导航 JSON 的结构事实（补充 F3–F5）

- **`source_id` 由路径算出**：按任务视图的 1,849 条数据块，`source_id` 全部等于 `"src_"` 加上 `sha256(original_path)` 的前 12 位，没有重复。
- **两个路径字段没有区别**：`original_path` 和 `direct_path` 在这 1,849 条里全部相同。
- **`sources[].entry_path` 能推出来**：两个视图共 3,697 条数据块，其中 3,691 条可以用"所在链接的 `entry_path` 加上 `direct_path` 去掉链接目标前缀后的部分"推出来。剩下 6 条链接够不着，写成了绝对路径，即 alpha 的 3 个已删除副本，两个视图各一份。
- **`view`/`format`/`version` 和目录位置**：70 份里有 68 份和目录位置一致。另外 2 份是 `format=archives`，对应的目录是 `tar、tar.gz（含分卷）`。
- **14 项的结构**：编号、名称、顺序在 35 份 `数据集信息.json` 里完全一致。
  - "采集机器人型号"和"FPS"两项，有 29 份是固定写法，即 `` 本地 robot_type=`…` `` 和 `N（meta/info.json 声明的数据帧率）`。
  - 另外 6 份是自由文字：EgoProDemo、EgoProStandard、R1_lite_table_withdrawing_mcap、agibot_world_2026、agibot_world_alpha、galaxea_open_world。
- **数据盘绝对路径出现的次数**（两个视图合计）：
  - `原始路径.json`：7,634 次
  - `子任务.json`：16,908 次
  - `数据集信息.json`：608 次，都在第 2 项"地址"和第 14 项"信息来源与核验日期"的 Markdown 正文里，35 个数据集都有。
  - 只看 agibot_world_2026：每个视图 821 + 2,638 + 4 处。agibot_world_alpha：每个视图 475 + 863 + 10 处。
- **体积**：两个视图的 JSON 合计约 38 MB，其中 `子任务.json` 占 35.7 MB。
- 来源：`python3 -I .scratch/platform-v1/assets/11-dataset-contract/schema_check.py /mnt/datasets`（不跟随软链接，0.13 秒）。
