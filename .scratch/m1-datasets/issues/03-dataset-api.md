# 数据集接口

Status: done

分级：骨架关卡。理由：这是跨模块的接口，前端第 04 张要照着它的 OpenAPI 并行开工；"接口不碰存储根"要在骨架里写成一条能检查的边界（3.0 第 1 条"跨模块接口"）。

## 依据

- M1 spec 第 03 张，"各部分的范围"四。
- 「数据集板块的数据契约」（11）Answer：Q12（大小和 10-12 记录值）、Q13（详情页规则、`validation_status` 中文标签）、Q14（面板），以及"网页不碰存储根"。ADR 0006 的"Web 的边界"一条。
- 「数据集浏览界面」（16）Answer：筛选项，默认按机器人型号，型号标签放进"更多筛选"，加"数据来源"；按账号记住布局。
- 「核心领域模型与术语」（13）：型号和型号标签的对应关系，数据来源的取值。
- M1 spec「待负责人确认」第 3 条（已按建议定）：型号表为空时，默认位置临时显示型号标签筛选。
- ADR 0005：Web 只提交作业，不写导航层。
- **依赖**：第 01 张合并以后开工（用它的索引表结构）。可以和第 02 张并行。不需要新依赖。

## 目标

前端拿到数据集板块需要的全部数据：两棵树、筛选后的列表、详情、面板，还能"重新检查"单个数据集、手动提交统计大小、记住每个账号上次选的布局。

## 范围

**`/api/datasets/*`**（所有登录账号可用）

读索引的：
- **两棵树**：按格式和按任务，带数量和大小。没统计过的，大小用 10-12 的记录值，并标明出处。
- **列表与筛选**：
  - 机器人型号：经"型号 → 型号标签"的对应关系筛选。
  - 型号标签：原始字符串。
  - FPS：四舍五入成整数。
  - 数据来源。
  - "未知"单独作为一项。
  - 型号表为空时，接口照常工作，告诉前端"没有登记型号"（spec 待确认第 3 条）。
- **一致性面板**：四组两级，同类合并，带样例；存储根离线时有顶部提示。
- **链接状态和大小**，带统计时间。

直接读导航层的（Web 可以只读导航层本身，ADR 0006）：
- **详情**：三份 JSON 照文件原样返回，加上推导字段和 `validation_status` 的中文标签。`子任务.json` 单独一个接口。
- 文件比索引新时（指纹对不上），返回"索引过期"标记。

提交作业的：
- **重新检查**：提交一个单数据集扫描作业。
- **统计大小**：手动提交一次。
- 这两种都只插作业行，不在 Web 里执行。

账号偏好：
- 按账号读写"上次选的布局"（A、B、C）。存在数据库里，表结构在骨架关卡定。

**边界**
- 接口代码不访问存储根：不 import、不调用第 02 张的存储根访问。这一条写进 import-linter 契约，或者 `check_contracts.py` 已能核对的形式，在骨架关卡定。
- OpenAPI 导出和前端类型照 M0 的做法生成。

## 验收

1. **真实导航层只读演练**（排在前半段）：骨架提交、Codex 交回树和详情两组接口时，Claude 在沙箱外做一次：
   - 用第 01 张对真实导航层只读建的索引（临时状态目录）起 Web；
   - 用 curl 登录后，取两棵树、取最大的 `子任务.json`（约 14 MB），记下响应时间和大小；
   - 整个过程中，把配置里两个存储根的路径改成不存在的目录，接口照常返回；
   - 不写 `/mnt`。
2. **不碰存储根**：import-linter（或契约检查）能拦住接口代码 import 存储根访问；测试里把假存储根设成不可读，所有接口照常返回。
3. **筛选**：型号标签、FPS 四舍五入（例如 29.97 → 30）、数据来源（全部"未知"）、"未知"一项，各一个测试。型号表为空、型号表有一条对应关系，两种情况下"按机器人型号"的行为都对。
4. **详情与过期**：改动假导航层里一份 JSON 后，详情返回"索引过期"标记；`子任务.json` 只在单独的接口里返回。
5. **作业**：重新检查、手动统计各提交一个作业，提交人是当前账号；Web 进程不执行它们。
6. **布局偏好**：同一账号写了以后，换一个会话读出来相同；不同账号互不影响；未登录 401。
7. **OpenAPI**：导出的文档和生成的前端类型是最新的（M0 的过期检查）。
8. **检查链**：同第 01 张验收第 9 条。
