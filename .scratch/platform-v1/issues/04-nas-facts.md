# NAS 接入事实

Type: task
Status: open

## Question

NAS 接入之后，采集它的事实，供「[软链接接口规则](12-link-rules.md)」使用。NAS 预计 2026-10-27 前接入（0001），硬件到位之前这张票无法开始。

这张票需要负责人在场（HITL）：agent 给出一份逐条核查的命令清单，由负责人执行，或授权 agent 只读执行。

要采集的事实：

- **挂载**：协议（NFS/SMB）、挂载点路径、`/etc/fstab` 选项（是否 `nofail`）、挂载后的属主和权限；平台进程能否只读访问。
- **容量与吞吐**：实测的读、写吞吐，以及总容量。
- **掉线行为**：NAS 不在线时挂载点是什么样（空目录、报错，还是一直卡住）。
- **智元数据迁移计划**：agibot_world_2026（13.2 TB）和 agibot_world_alpha（9.0 TB）迁到 NAS 的先后顺序和时间窗口。这张票只定计划，不执行迁移。

**完成标准**：以上各项都有实测值或明确结论，写成 `docs/brief/000N-环境事实更新-NAS.md`，每条附来源命令；本票 Answer 写要点并链接过去。
