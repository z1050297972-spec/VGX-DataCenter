# 下载页面

Status: in-review

分级：直做。理由：在第 01、02 张的契约上加接口和页面，不新增领域对象。如果需要改第 02 张的作业参数或表结构，升为骨架关卡。

## 依据

- M2 spec 第 03 张；「负责人决定」第 2、3、4、6 条。
- M0/M1 已有页面：作业列表与详情（`src/web/src/jobs/`）、外壳和路由（`router.tsx`、`accounts/Pages.tsx`）、接口类型生成（`make api-types`）。复用作业进度轮询，不另写一套。
- ADR 0006：Web 不访问存储根。预览要读镜像、要看存储根剩余空间，所以"预览"是 worker 里的一个只读短作业（或者复用下载作业的计划阶段），Web 只提交和读结果。具体做法实现时定，写进最终回复。

## 目标

成员在"下载"页面填仓库、选筛选和参数，看预览，确认后提交；在作业页看进度并调整并发和限速；管理员设置 token、清理暂存目录。

## 范围

- **下载页**：仓库类型（数据集/模型）、仓库编号、版本（默认 main）、目标存储根（只列可写的）；模型另有"子目录"输入框（默认值显示出来）。
- **筛选**：数据集预览出来以后，列出相机，勾选"不要视频"或取消某几路相机；高级里有包含/排除模式。
- **预览**：版本（commit）、episode 数、帧数、FPS、robot_type、相机、文件数、筛选后大小、已在暂存区的大小、存储根剩余空间、够不够。预览失败（镜像不生效、gated 没 token、空间不够）显示诊断卡片。
- **高级参数**：spec 第 6 条那张表，默认收起，只露出"总限速"；每项一句说明、默认值、范围，前端校验和后端一致（以后端为准，422 显示在字段旁）。
- **作业详情**：下载作业多显示：当前速度、文件计数、实际生效的参数；运行中可以改"同时下几个文件"和"总限速"，提交后显示"已生效"或失败原因。
- **暂存区**：（Web 不读存储根：ADR 0006 2026-10 修订后只有原文件查看器例外。列表由 worker 的只读作业生成、存数据库，页面读结果并显示生成时间。）列出可写存储根上 `暂存/下载/` 下的目录（repo、commit、大小、最后修改时间、是否有作业在用）；管理员可以删除没有作业在用的目录，删除前确认，删除是 worker 作业，进操作日志。
- **token**：管理员页里设置/清除 HF token；只显示"已设置/未设置"，不回显。写文件 0600。写 token 是 Web 写状态目录（不是存储根），符合 ADR 0006；如果现有代码约定状态目录也只由 worker 写，实现时按约定改成作业。
