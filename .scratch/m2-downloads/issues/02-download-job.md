## 目标

成员提交一个"下载"作业后，worker 按第 01 张的计划，经 hf-mirror 把文件下进暂存目录，逐个校验；进度、速度、取消、运行中调参都可用；取消或断电后重新提交（或 worker 重启续跑）不重下已完成的文件。

## 范围

- **作业类型"下载"**：登记进生产登记表；恢复方式"续跑"；并发上限 1；条目 = 一个文件。参数：第 01 张的 `DownloadRequest` 字段，加 spec 第 6 条的 aria2 参数（含默认值和范围校验）。参数里不能有 token（登记表本身也禁止秘密字段）。
- **阶段**：探测镜像 → 解析版本 → 列清单 → 预检 → 下载 → 校验 → 完成。数据集停在暂存目录（入库是第 05 张）；模型下完后在同一文件系统内改名到 `model_weights_path`，目标已存在就失败，不覆盖。
- **aria2**：worker 起 `aria2c --enable-rpc` 子进程（只听 127.0.0.1、随机 rpc-secret、`--continue=true`、`--auto-file-renaming=false`、`--file-allocation=none`，显式不设代理），按进程组管理。逐个 `aria2.addUri`，URI 一律是镜像的 `resolve/<commit>/<path>`，LFS 文件带 `checksum=sha-256=…`；token 用请求头传，不进命令行参数（`ps` 能看到命令行）、不进日志。aria2 可执行文件的路径来自配置（本机在 conda 的 bin 里，运维手册要写）。
- **只走镜像**：aria2 遇到跳往 `huggingface.co` 的重定向不能跟过去。镜像自己的 302（例如跳到镜像的 xet/CDN 域名）允许。具体怎么拦（aria2 选项，或先由 worker 解析一次跳转），在骨架里定，并写进风险。
- **curl 兜底**：某个文件 aria2 失败到上限后，对这个文件改用 `curl -C - --retry N`，同一限速；同样不跟随到 huggingface.co（`--proto-redir`/不加 `-L` 后自己判断，骨架里定）。
- **校验**：aria2 校验过的 LFS 文件记为通过；curl 兜底的和非 LFS 小文件由 worker 算 sha256 或 git blob sha1，外加大小。失败删掉重下一次，再失败记为失败条目。
- **续跑与跳过**：每次执行都重新走计划；暂存目录里大小一致、校验通过的文件跳过（跳过的也记条目）；半截文件和 `.aria2` 控制文件交给 aria2 续传。校验结果可以缓存在暂存目录里的一个清单文件中，避免几 TB 的数据每次重算哈希（格式骨架里定）。
- **进度**：每秒最多一次（M0 规则）：已完成字节 + 进行中字节 / 总量、当前速度、文件计数（总数、完成、失败、跳过）。
- **取消**：先 RPC `forceRemove` + `shutdown`，再按 M0 的进程组 TERM→KILL；暂存目录不清理。
- **运行中调参**：只允许改"同时下几个文件"和"总限速"（`aria2.changeGlobalOption`）。需要一个从 Web 到 worker 的通道：在作业记录上放"待生效的调整"，worker 在进度循环里读取并应用、写回生效值。如果 M0 的作业模型里没有这类通道，在骨架里提出最小的扩展（这会改数据库表，属于对外行为变化，骨架里写清楚，执行线审）。
- **429**：放慢而不是狂刷：aria2 的重试间隔加上 worker 在连续 429 时整体降并发（具体规则骨架里定）。

## 验收

- 测试不访问网络、不真起 aria2：aria2 RPC 和 curl 都有替身；另有一个用本机 aria2c + 本地 HTTP 测试服务器（`http.server`，监听 127.0.0.1）的集成测试，验证续传、sha256 校验失败、取消后重新执行跳过已完成文件。
- 镜像 308 回官方站：作业在下载前失败，诊断写明"网络不满足：镜像不生效"和处理办法。
- 本地测试服务器返回跳往 `huggingface.co` 的重定向：aria2 和 curl 都不跟过去，该文件失败。
- token 不出现在 aria2/curl 的命令行、作业参数、日志、诊断里（测试断言）。
- 取消后暂存目录保留；重新执行时已完成文件计为跳过。
- worker 中途被杀（测试里模拟中断）后续跑：已完成文件不重下。
- 运行中调整并发和限速：替身收到 `changeGlobalOption`，作业详情能读到生效值。
- 作业结果：全成功、有跳过、部分失败、全部失败四种各一个用例。
- `make check` 全绿。
