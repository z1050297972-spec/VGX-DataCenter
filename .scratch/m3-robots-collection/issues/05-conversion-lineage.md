# 登记转换关系（人工血缘）

Status: ready-for-agent

分级：直做。按"只做关键测试"。写导航层，要做副本演练。

Blocked by: 03（顺序上排在 04 之后，和 04 不改同一处时可并行）

## 依据

- 负责人（2026-11-08）问答 3 选"要，写进来源.json"；决定记录："转换产物用血缘连回去……M3 只做人工登记这一条关系；转换作业自动写血缘留到 M4"。
- ADR 0008：血缘写在按任务入口的 `来源.json`，第 2 版只存 `dataset_id`、`dataset_name`、`collection_task_id` 和血缘记录。

## 契约

- **记录格式**：`来源.json` 的血缘数组里追加一条人工记录：

  ```json
  {"kind": "manual", "input_dataset_ids": ["dataset-29"], "note": "mcap 转 LeRobot v2.1",
   "recorded_by": "张三", "recorded_at": "2026-11-08T12:00:00+08:00", "job_id": 1400}
  ```

  - `input_dataset_ids`：1–8 个已存在的 `dataset_id`，不能含自己。`note` 0–500 字符。`recorded_by` 是提交人显示名，`recorded_at` 带偏移的本地时间，`job_id` 是写入作业编号。
  - 现有血缘数组的键名、已有记录照旧（先读现有代码确认数组的键名；如果 v2 里还没有数组，就用 ADR 0008 里的写法定一个，写在最终回复里）。
- **作业**：`nav_lineage_preview`，参数 `{dataset_id, action: "add" | "remove", input_dataset_ids?, note?, record_index?}`：
  - `add` 追加一条人工记录；`remove` 只能删 `kind: "manual"` 的记录（按下标），工具写的记录一律只追加、不能删（ADR 0008 只追加规则对工具记录不变；人工记录可删，ADR 修订由执行线写）。
  - 走预览 → 确认（`nav_write_apply`）；权限同字段编辑；只改 `来源.json`，其余文件不动，其他键值和顺序不变。
- **索引与显示**：扫描把血缘的输入关系投影进索引（新迁移）。详情页加"转换关系"一块：上游"由 X 转换"（名称可点，带说明），下游"转换出 Y"（从别的数据集的记录反查）；每条人工记录有"删除"，块里有"登记转换来源"按钮（选数据集，可多选，加说明）。
- `collection_task_id`：采集任务就是数据集本身，这个键不再写有意义的值；读时忽略，写时保持原样（不新增、不删除）。

## 范围

1. **后端**：作业、接口 `POST /api/navigation/lineage/preview`、索引投影、详情接口返回上下游；测试。
2. **前端**：详情页"转换关系"块、登记与删除（预览 → 确认）。
3. **手册**：导航层手册讲人工血缘记录；使用手册"登记转换关系"（执行线写）。
