   - ADR 0008（接在 M3 修订节之后）：工具目录不改动，登记包放平台仓库 `tools/<工具名>/`（清单、配置副本）；版本以程序 sha256 为准，取代"工作区不干净就拒绝"；工具在 bwrap 里运行（只读绑定、只有暂存目录可写、不联网）；转换暂存目录 `暂存/转换/<作业编号>/`；不建工具的数据库索引。
3. **术语表**：登记包、程序指纹、工具状态、转换回执、入库检查结果的三种取值。
4. **手册**：使用手册加"工具库""转换与入库"；运维手册加"登记或重新登记一个工具"（算 sha256、复制配置、改 `tool.toml`，工具目录不动）。
