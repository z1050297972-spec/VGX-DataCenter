## 硬约束（负责人："功能代码上不要做任何改动，我担心会造成事故"）

- tsx 只许改布局容器：可以换成或套上 antd 布局组件、分组、调整顺序。不改逻辑、状态、查询、事件处理、文案（包括按钮名和 aria-label）、接口。
- **测试文件一个都不改，现有测试原样通过。**如果某个 antd 组件会让现有测试失败（例如 `Descriptions` 把"标签：值"拆进两个单元格，导致按整段文字找的测试找不到），就换一种不破坏测试的 antd 写法，比如保留原文本节点，外面套 `Card`/`Flex`。不要为了用某个组件去改测试。
- 不引入新依赖，不自己写通用组件。

## 范围

### 1. 全局（`shell.css`）

- **间距档位**：`--rdp-space-1` 到 `--rdp-space-7` 改成 4/8/12/16/24/32/48，删掉 `--rdp-space-8`。现在的档位是 4/6/8/12/16/18/20/24，换算后同名变量的值会变，所以**全部 CSS 里的用法都要逐处重新对应**：例如原来的 6px 对应新的 8px，18px、20px 按所在位置归到 16 或 24。组内间距 ≤16，组与组之间 ≥24（10.15）。`--rdp-space-select-*` 是给 antd 下拉框内边距对齐用的，保留。
- **宽度变量**：`--rdp-width-120/150/…/640` 这类按数值命名的变量，改成按用途命名，例如 `--rdp-width-filter`、`--rdp-width-select-wide`。值可以合并，用到的地方一起改。
- **shadcn 质感**：
  - 卡片（antd `Card` 和页面里的面板）用 `--rdp-line` 细边框加 `--rdp-surface`，不用阴影，圆角用 `--rdp-radius-card`；
  - 表头背景透明，表头文字用灰色小字；
  - 强调色只用在主按钮、选中状态和链接；
  - 说明文字用 `--rdp-muted` 小字号。
  - 顶栏和底部菜单的玻璃效果保持不变。
- **页头样式**：配合第 2 条的 `Breadcrumb` 加 `Typography.Title`。标题放大，字距略收；小标签用灰色小字。

### 2. 数据集浏览页（布局 A）

涉及 `datasets/Pages.tsx`、`Filters.tsx`、`LayoutA.tsx`、`BrowserParts.tsx`、`Details.tsx`，以及详情里的分节组件（`Information.tsx`、`DataOrigin.tsx`、`FieldEditing.tsx`、`Repoint.tsx` 等，只改布局），样式写在 `browser.css` 和各模块已有的 CSS 里。

1. **页头**：`Breadcrumb`（数据集 / 浏览）加标题；同一行靠右依次是布局切换（`Segmented`）、"新增数据集"（唯一的主按钮）。用 `Flex` 排。布局读取和保存失败的 `Alert`、存储告警，放在页头下方，醒目程度不变（10.12）。
2. **筛选卡**：五个筛选项放进一张 `Card`。用 antd 栅格（`Row`/`Col`）等宽排成一行，标签在输入框上方，1280 宽也排得下；窄屏时自动换行。用 `Affix` 吸顶，吸住时不能盖住玻璃顶栏。筛选的取值、联动、URL 同步一律不动。
3. **说明行**：布局 A 右侧说明栏那句话，挪到筛选卡下方做一行灰色提示；"一致性面板"按钮放在同一行右侧。布局 A 改成两栏：视图树和列表/详情。
4. **视图树、列表各放一张卡片**。列表表格用中等行高；数据集名一行，"场景 / 任务 / 机器人型号"合成名字下方的一行灰色小字，用 `·` 分隔；长名称单行截断，悬停显示全文（antd `ellipsis`）；路径类的列完整显示，用等宽小字号。
5. **详情**：
   - 头部一行：返回、标题、操作按钮（建链、改指向）。
   - 编号、路径、两个时间做成两列摘要，用 `Descriptions` 或栅格，注意上面"硬约束"里关于测试的说明。
   - 后面各分节（跨视图跳转、数据来源、导航层字段、数据集大小、链接状态、数据块……）各有一个小标题，分节之间用细分隔线隔开，不套卡片（10.14）。
   - 每节只保留一个主样式按钮，其余是默认按钮或文字按钮，全部可见。
6. **布局 B、C**：不专门调整。共用部件改了，它们自动跟着变，但不能错位或失效（现有测试会覆盖到）。
