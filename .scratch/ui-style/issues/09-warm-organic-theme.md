## 设计取值（实现以此为准）

| 用途 | 值 |
|---|---|
| 页面底色 | `#fffaf4` |
| 卡片表面、弹层 | `#fff` |
| 次级表面（筛选托盘、日志框、分段控件底） | `#ffede0` |

| 边线 / 加深边线 | `#f3dccb` / `#ebc5ac` |
| 强调色（链接、选中、复选框、开关、焦点环、页签） | 深橙 `#a64b08`，悬停 `#8f3f05`，按下 `#783403`，浅底 `#ffe9d6` / `#ffdcc0`，边框 `#f3c39c` / `#e9a56f` |

| 停靠菜单 | 底 `rgb(200 64 43 / 94%)`（不透明降级 `#c8402b`），字 `rgb(255 248 242 / 86%)`，当前页胶囊底 `#fff8f2`、字 `#c8402b` |

深色：

| 用途 | 值 |
|---|---|
| 页面 / 表面 / 弹层 / 次级表面 | `#171210` / `#211a17` / `#2a211d` / `#2c221e` |
| 正文 / 次要 | `#f3e9e2` / `#a8978f` |
| 边线 / 加深边线 | `#372b26` / `#4d3d36` |
| 强调色 | 文字用 `#ffab73`；填充类（复选框、开关）由 antd 深色算法从种子 `#e8752a` 推导 |
| 主按钮 | 近白 `#f3e9e2`，悬停 `#fff8f2`，按下 `#ddd0c8`，深色字 `#171210` |
| 停靠菜单 | 底 `rgb(168 54 36 / 90%)`（不透明降级 `#a83624`），当前页胶囊底 `#f3e9e2`、字 `#a83624` |

为什么强调色用深橙、主按钮用暖墨色：珊瑚红和 antd 危险按钮的红色太接近，主按钮或链接用珊瑚红时，"确认"和"删除"靠颜色分不开（10.12）。珊瑚红只用在不承担操作语义的地方：停靠菜单底色和背景色块。**危险按钮、成功/失败/警告的语义色一律不改。**

对比度：所有正文、次要文字、链接在各自底色上不低于 4.5:1（次级表面 `#ffede0` 上的强调色文字也要满足，不够就把那一处换成正文色或加深，不要降低标准）。交付前自己算一遍，在最终回复里列出算过的组合。

主按钮反色的做法沿用第 08 张：只用 antd 的 Button 组件 token，不改全局 `colorPrimary` 为墨色，也不改全局 `colorTextLightSolid`。

形状：
- 圆角：卡片 24px，控件 12px，小标签 6px，树节点 10px，登录卡 32px，胶囊 999px。
- 卡片仍是 1px 细线，不加阴影（10.15）。

字体：
- 页面大标题（页头 `Typography.Title`）和登录页标题改用衬线栈：`"Noto Serif CJK SC", "Source Han Serif SC", "Songti SC", "STSong"`，**后面直接接现有的 `--rdp-font` 无衬线栈，不写通用族 `serif`**。这样没装中文衬线字体的机器会落到现在的无衬线字体，而不是系统默认宋体。新变量 `--rdp-font-display`。字重 600，字距 `0.02em`（替换第 08 张的 `-0.025em`）。
- 不打包新字体，不改 `src/web/src/fonts/`。正文、等宽字体不变。

背景色块（纯装饰）：
- 两组有机色块，固定在视口角落，不随内容滚动，放在所有内容之下，不接收指针事件：右上一组（橙 `#ffa62b` + 珊瑚红 `#ff5a5f` + 一个小圆点），左下一组（浅桃 `#ffdcc0` + 珊瑚红）。形状参考原型 CSS 里的两段 SVG，可以直接取用路径。
- 用 CSS 背景图实现（SVG 数据 URI，或 `src/web/src/` 下新增 `.svg` 文件由 CSS 引用，二选一）。不新增 DOM，不改 tsx。
- **右上色块不能压到页头右侧的操作按钮和告警条**：整体收在顶栏高度附近、宽度不超过约 280px；1440 和 1280 宽度下，色块和任何按钮、输入框、文字都不重叠（顶栏右侧的账号文字和"登出"按钮可以在色块之上，但文字对比度仍须达标：必要时给顶栏右侧区域保留现在的毛玻璃底）。
- 视口宽度小于 1100px 时不显示色块。
- 深色模式下色块整体透明度降到约 35%。
- `html[data-rdp-plain]` 下不显示色块；色块本身没有动画，不受 `prefers-reduced-motion` 影响。
- 为了让色块透出来，页面底色只画在 `html`/`body` 一层；其余布局容器（antd `Layout` 等）背景透明。卡片、顶栏、弹层保持不透明或原有毛玻璃。

各部件（只列和第 08 张不同的地方，没列的保持第 08 张的外观，颜色随变量变化）：
1. 筛选卡：次级表面换成浅桃 `#ffede0`，仍无边线；里面的下拉框保持白底。
2. 卡片标题左侧的 6px 小方块改成 8px 实心圆点，颜色橙 `#ffa62b`（深色 `#e8752a`）。
3. 树选中项、分段控件选中项、页签墨条用新的强调色。
4. 表格、标签、进度条、日志框、告警（除全局告警底色外）结构不变。

## 范围与边界

- `src/web/src/shell.css`：变量、全局部件样式、背景色块、降级。
- 各模块 CSS（`src/web/src/**/*.css`）：只在引用了旧取值或和新设计冲突时改。

- 除 `mountWeb.tsx` 以外的任何 `.ts`/`.tsx`。
- 任何测试文件（`*.test.ts(x)`、`testSetup.ts`、`testSupport.ts`）。**测试一个不改、全部通过，是"不影响现有功能"的硬性证明。**

- `docs/`：规范文字（10.15）由执行线在合并时更新。

规范：
- 遵守 CODING_STANDARDS 10.7–10.15。新颜色、尺寸先在 `shell.css` 定义 `--rdp-*` 变量再使用；不写 `!important`（原型里的 `!important` 不能照抄）；`mountWeb.tsx` 的种子色和 `shell.css` 同步，两边注释互相指向，注释里的"ui-style 08"按实际改成"ui-style 09"或并列。
