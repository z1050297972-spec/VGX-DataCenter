## 范围

1. **编辑器**（`FieldEditing.tsx`、`FieldInputs.tsx`，纯前端）：
   - 不再单独渲染 `robot_model`、`scene`、`tasks` 三个输入。后端 `INFO_LABELS` 和提交路径不变（仍然是 `["robot_model"]`、`["scene"]`、`["tasks"]`）。
   - 第 5 项（name=采集机器人型号）那一行：先是原来的机器人型号输入（含 robot_type 参考提示），下面是第 5 项文字框。
   - 第 6 项（name=任务与场景）那一行：先是场景选择和任务标签（复用 M1.5-06 的 `ClassificationInput`），下面是第 6 项文字框。
   - 按 number+name 找第 5、6 项；文件里没有对应项时，这三个输入退回原来的单独位置，不能丢。
2. **新建数据集**：
   - 后端 `DatasetPreviewParameters` 加可选 `information`，默认 None：
     ```
     information: {
       fields: [{number: int, value_markdown: str}],   // number 1–14，不能是 4，不能重复；可以只给一部分
       robot_model: str = "",
       scene: str = "",
       tasks: list[str] = [],
     }
     ```
     scene/tasks 的规范化和校验复用 `_field_rules._classification_value` 的规则（去空格、去重、拒绝 unlabeled 和空项）。非法输入 422。
   - `new_snapshot` 把给出的 `value_markdown` 写进对应项；`robot_model`、`scene`、`tasks` 非空时写到 `数据集信息.json` 顶层，空的不写。按格式副本照现有流程同步。预览差异里能看到这些值。
   - 前端"新建数据集"表单加一个"14 项数据集信息（可选）"分节：13 个多行文字框（第 4 项显示"自动计算"，不可填）；第 5 项上面有机器人型号输入，第 6 项上面有场景/任务选择，和编辑器同一套组件。
   - 下载入库（`downloads/Ingest.tsx`）这次不改。
3. 使用手册同步改。
