# 原文件只读查看器（含视频）

Status: done

分级：直做。理由：只读，不写导航层，也不写数据盘；接口和页面照第 03–05 张的写法做。

## 依据

- 决定记录 `.scratch/m1.5-edit-view-classify/decisions.md`：Web 可以只读存储根，并带超时。负责人原话："用户通过接口看不到具体的视频、info.json等原文件"。
- ADR 0006：存储根、只读。本票会修订第 03 张"接口不碰存储根"的契约：只读查看器这一个模块可以读存储根，其余数据集接口照旧不碰。
- 依赖：M1 第 01–08、10 张已合并。

## 目标

在数据集详情里，可以逐级浏览每条链接指向的数据目录，查看 JSON 和文本文件、图片，在线播放 MP4。全程只读。

## 范围

- **后端**，只读接口，所有登录账号可用：
  - 列目录：给定数据集编号、链接名和相对路径，返回条目（名字、类型、大小、修改时间）。分页，单页上限 500 条。
  - 读文件：文本和 JSON 返回原字节，单个文件上限 32 MiB，超过就提示"太大，请下载工具查看"；图片返回原字节；MP4 等视频支持 HTTP Range 请求，按需分段返回，可以拖进度条。
  - **路径安全**：路径必须在这个数据集已登记的链接目标之内。realpath 之后不能越出，也不能顺着软链接跳出存储根；不接受 `..`。存储根离线或超时返回 502 和五段诊断，不挂住 Web 进程（复用 M0 第 10 张的超时访问）。
  - 读取带 O_NOATIME（第 02 张的做法），EPERM 时退回普通读取。
  - 只读：没有任何写、删、改名的接口。
- **前端**：
  - 详情里加"查看原文件"：先选链接，再像布局 C 那样逐级进目录；
  - 右侧预览：JSON 格式化显示（大文件复用第 04 张的 worker 分页），文本原样显示，图片直接显示，MP4 用 `<video controls>` 播放，Range 请求由浏览器自己发；
  - 1280×900 下不能出现横向滚动条，长名字用省略号截断。
- 修订 import-linter：查看器模块可以访问存储根，第 03 张的禁入契约对其余模块照旧。

## 验收

1. 测试：越界路径（`..`、绝对路径、软链接跳出去）一律拒绝；Range 请求的正确性（206、Content-Range、首尾和越界的范围）；超过 32 MiB 的文本被拒；存储根离线返回 502。
2. 真实演练（执行线，沙箱外）：起 Web，打开 libero_10 的 meta/info.json、一个 parquet 所在目录、一个 MP4 视频，在浏览器里播放并拖动进度条。前后比对 /mnt 的写入扇区数，必须不变。
3. 检查链：make check 全绿、0 skipped，变异抽查。
