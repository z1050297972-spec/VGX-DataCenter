# 场景、任务的值可以统一删除

Status: in-progress

分级：直做。理由：复用写导航层的预览 → 确认 → 写入 → 可撤回流水线和第 15 张回填作业的写法，只改 `数据集信息.json` 顶层的 `scene`、`tasks`，不改文件格式和已有接口。按"只做关键测试"。

## 依据

负责人（2026-11-06）：

> 场景和任务，我们已经添加了一些信息，却无法对这些进行进行删除操作，可否加上？

负责人选择：删除指的是"从下拉候选里删掉某个值"，也就是让这个值从所有用到它的数据集里去掉，下拉里不再出现。内置词表项的隐藏不做。

## 现状（2026-11-06）

- 下拉候选 = 内置词表（`jobs/datasets/vocabulary.py`，零计数也显示）+ 各数据集 `数据集信息.json` 里出现过的自定义值（第 06 张）。自定义值没有单独的存放处，没有数据集再用它，它就自动消失。
- 正在使用的自定义值：场景 `实验室`（2 个数据集）；任务 `多任务聚合`（12）、`洗碗`（2）、`叠衣服`（2）、`搭乘电梯`（1）、`开冰箱`（1）。

## 契约

- 新作业 `nav_classification_remove_preview`，参数 `{kind: "scene" | "tasks", value: string}`。
  - 找出规范副本 `数据集信息.json` 的 `scene`（读取规则照第 12 张，旧字符串当一项数组）或 `tasks` 含 `value` 的数据集，从数组里去掉这个值；`scene` 一律写成数组，去光了写 `[]`（即未标注）。
  - 其余键值和键顺序一个字节都不改（同第 15 张回填的硬约束）；按格式副本照现有流程由规范副本同步。
  - `value` 为 `unlabeled` 或没有任何数据集使用时返回 422。
  - 确认、撤回复用现有 `nav_write_apply`、`nav_revert_preview`。权限与字段编辑相同。
- 接口：`POST /api/navigation/classification/remove/preview`，返回作业编号。候选和计数沿用现有 `GET /api/datasets/filters`，不新增读接口。

## 范围

1. **后端**：上面的作业（新文件 `navwrite/classification_remove.py`）、接口、注册；测试。
2. **前端**：数据中心工具栏加"管理场景/任务"按钮（放在"回填数据集信息"旁边），打开后分"场景""任务"两页，每行显示名称、编码、使用的数据集数、是否内置词表，带"删除"按钮：
   - 计数为 0 的不能删（内置词表项会一直留在列表里，提示"内置词表项，没有数据集在用"）。
   - 点删除 → 预览（列出会改到的数据集，以及哪些会变成未标注）→ 确认 → 作业完成后刷新候选。可在作业详情撤回。
3. **手册**：使用手册加一节"删除场景/任务的值"。
4. **大小统计说明**（负责人 2026-11-06 加入本票："这三条提示信息放到页面作为说明吧"）：`Sizes.tsx` 的"统计大小"下面加一段说明（antd 次要文字，三条列表），文字照下面，可调措辞不改意思：
   - 每天一次：本地时间凌晨 03:00 统计全部数据集。如果那时平台没在运行（例如关机或 worker 没启动），下次启动时补统计一次，当天只补这一次。
   - 写导航层之后：只重新统计这次写入涉及的数据集（例如回填、编辑字段之后）。
   - 手动：点"统计大小"立即统计。

## 验收

1. **关键测试**：
   - 删除任务 `洗碗`：用到它的 2 个数据集 `tasks` 去掉该项，其余键值和顺序不变，格式副本同步；撤回后逐字节还原。
   - 删除某数据集唯一的场景：写成 `scene: []`，筛选里归"未标注"。
   - `unlabeled` 或没人用的值返回 422。
   - 前端：计数为 0 的行没有可用的删除按钮；点删除会先出预览；大小区域能看到三条统计说明。
