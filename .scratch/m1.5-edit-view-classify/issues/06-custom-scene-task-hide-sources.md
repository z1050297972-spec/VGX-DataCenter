执行线提问，负责人的选择：
- 自定义方式：**直接输入新值**。在下拉框里打字就能新建，值存进 `数据集信息.json`。编辑别的数据集时，下拉里也能选到别人已经用过的自定义值。不建数据库表，也不做词表管理页。
- 词表外的值：**不再提示**。自定义值和词表值显示方式一样，不标"（不在词表）"，一致性面板也不给提示。
- 数据块：指的是**数据集详情里的"数据块"表**，处理方式是**直接去掉**。后端接口保留。

执行线查实的现状：
- 后端 `navwrite/_field_rules.py` 收到 scene/tasks 时，任何文本都接受，不对照词表校验。筛选候选（`dataset_browser/_classification.py::options`）、按场景树（`scene_path` 会编码斜线）、列表和详情显示，都已经能按原值处理词表外的值。
- 词表外的值会在这三处被标出来：前端编辑器 `FieldInputs.tsx::classificationOptions`（标"（不在词表）"并且禁用）；后端筛选候选的 label；一致性面板 `_entry_checks.py::_vocabulary`（`VOCABULARY_UNKNOWN` 提示）。
- 数据块表是 `Entries.tsx::DatasetSources`，只在 `Details.tsx:182` 用了一次。

## 范围

1. **编辑器可以输入新值**（`FieldInputs.tsx` 的 `ClassificationInput`）：
   - 场景单选、任务多选，保持现状；两者都可以直接打字新建一个值，回车确认。
   - 候选项依次是：词表项（显示中文名）、平台上已经有数据集用过的自定义值（来自筛选候选接口的 `scenes`/`tasks`，去掉 `unlabeled`，显示原值），最后是当前已选的值。重复的值只出现一次。
   - 已有的自定义值不再禁用，可以正常选中、取消。
   - 输入时去掉首尾空格；去完是空串的不收。
   - 只用 antd `Select`（例如 `mode="tags"`；场景是单选，用 `showSearch` 加"新建：xxx"候选，或者用 tags 并限制只能选一个，二选一，在最终回复里说明理由）。
2. **后端写入校验**（`navwrite/_field_rules.py`，scene/tasks 两个字段）：
   - 去掉首尾空格以后再存；tasks 里去重，保持原来的顺序。
   - 拒绝保留字 `unlabeled`（它是筛选里"未标注"的专用值，见 `vocabulary.UNLABELED`），按现有方式报 NAV_FIELDS / 422。
   - tasks 里有去掉空格后为空的项也拒绝。scene 是空串时照旧表示清空。
   - 其他校验不加。
3. **不再把自定义值标成词表外**：
   - 筛选候选 label 直接用原值，不加"（不在词表）"；
   - 一致性面板不再产生 `VOCABULARY_UNKNOWN`。枚举成员保留，因为已经存下来的旧发现记录还要能正常显示；
   - 前端编辑器里也不再出现"（不在词表）"；
   - `vocabulary.py` 模块说明和相关 docstring 改成新口径："词表是推荐值，可以自定义"。
4. **去掉数据集详情里的数据块表**：`Details.tsx` 不再渲染 `DatasetSources`，删除这个组件以及只给它用的代码和测试。详情页"链接状态"表（`DatasetLinks`）去掉"观察到的指向"这一列（负责人说的"观察到的方向"），其余列不变。详情接口里的 `sources`、`observed_target` 字段，以及其他用到数据块的功能（建链审核、改指向、编辑器里的原始路径.json 页签）都不动。
4a. **去掉详情页末尾的两个原文按钮**：`Details.tsx` 不再渲染两处 `NavigationDocumentViewer`（"打开 数据集信息.json""打开 原始路径.json"），组件 `Documents.tsx` 没有别处用到就一起删掉。"打开 子任务.json"保留。详情接口里的 `information`、`original_paths` 字段不动。
5. 使用手册（`docs/manual/` 里讲字段编辑和数据集详情的章节）同步改。没有提到的就不加。
